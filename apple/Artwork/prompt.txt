# Original launcher icon prompts

Built-in image_gen tool; no game or other reference assets supplied.

## Initial generation

Use case: stylized-concept
Asset type: original premium Apple Vision Pro launcher app icon, square 1024 x 1024 full-bleed image.
Primary request: an exceptionally polished dark Nordic fantasy icon, evocative of cold mountains and ancient craft, using only newly invented artwork. This is an original game launcher icon, NOT a reproduction of any game's emblem.
Scene/backdrop: deep obsidian and charcoal gray, subtle atmospheric smoke and a soft frosted stone gradient extending all the way to all four square edges.
Subject: one singular sculptural geometric crest, an original angular mountain peak / ice-cut rune-like shape carved from frost-silver metal. Bold, readable and elegant silhouette, broad enough to read at tiny icon sizes. A restrained warm champagne-gold inlay runs through a few interior facets. A small amount of negative space within the crest adds depth. It should feel hand-forged, mysterious, expensive and tactile, not a generic tech lettermark.
Composition/framing: straight-on, centered, crest occupies about 58 percent of image width and height; all meaningful shapes comfortably inside the central circular icon crop. Perfectly balanced optical weight. No surrounding frame.
Lighting/mood: dramatic cool silver edge light, soft warm gold reflections, physically plausible brushed metal facets, rich shadows. Sophisticated and restrained.
Color palette: smoke gray, obsidian, frost silver, warm white, a small champagne-gold accent. No purple.
Text: none.
Constraints: entirely original visual design, no reference images, no extracted game assets. No Skyrim or Bethesda logo, no Imperial dragon crest, no dragon silhouette, no characters, no recognizable franchise item, no game screenshot, no font/wordmark, no lettering, no watermark. No circle, badge border, or baked-in rounded-square corners. Opaque full square background; the operating system will apply its own mask.
